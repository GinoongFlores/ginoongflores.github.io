ginoongflores — design system v1

Monochrome

A minimalist black & white system for a resume-style portfolio. One typeface, no accent colors — hierarchy comes from weight, size, and tone. Dark and light modes are mirror images of the same tokens.

01 — Principles

Tone over color

Emphasis is created with grayscale steps, never hue. Interactive elements brighten on hover instead of changing color.

Content is the interface

Sparse chrome, generous whitespace, thin hairline dividers. Project screenshots are the only imagery.

Two modes, one system

Every token has a dark and light value. Components never hard-code a color — they reference the token pair.
